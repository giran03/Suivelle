Pages and blocks

A page is a column of blocks: paragraphs, headings, lists, tables, code, media and whole databases. You write with the keyboard, rearrange with the mouse, and every change saves on its own.

Writing as you type

Markdown shortcuts turn into blocks the moment you type them. Start a line with #, ## or ### for headings, - or * for a bulleted list, 1. for a numbered list, [] for a to-do, > for a quote and ``` for code. Inline, Ctrl B, I, U and E give bold, italic, underline and inline code.

Select text to bring up the selection toolbar for formatting, links and colour. Undo and redo cover everything, including block moves.

The slash menu

Type / anywhere to insert a block, then keep typing to filter. The same catalogue turns an existing block into another kind.

Moving blocks around

Hover a block to reveal its handle in the gutter. Drag it to move the block, or click it for a menu that duplicates, deletes, converts or schedules it. From the keyboard, Alt Shift ↑ and ↓ move a block, and Ctrl Shift D duplicates it. Select several blocks by dragging across them; the selection stays inside the pane you started in.

Structure that folds away

Toggles
Toggle lists and toggle headings hide their content until opened. Converting to or from a toggle keeps the rich summary and everything nested inside.
Tabs
Switchable panels with editable labels and a keyboard-navigable tab strip. Turning a block into Tabs puts it in the first panel; exports read every panel in order.
Columns
Place blocks side by side in two or three columns.
Table of contents
Lists the page's headings and jumps to them.
Synced blocks
One block of content shown in many pages. Edit it anywhere and every copy updates.

Code, equations and tables

Code blocks highlight syntax for the language you pick and carry a copy button beside the language picker. Equations are written in LaTeX and rendered with KaTeX; the renderer loads the first time you use one. Simple tables grow with Ctrl Enter for a row below and Ctrl Shift Enter for a column to the right.

Images, media and embeds

Drop or paste images, audio, video, PDFs and any other file. Files are stored inside your workspace, so they keep working offline. Images can be resized, aligned, captioned, given alt text and a private note, and cropped without losing the original (freeform, square, 4:3 or 16:9). Double-click opens a full-resolution viewer with zoom and panning, and animated GIF, WebP and APNG images keep their frames.

Paste a supported media link and Suivelle asks whether to keep the link or turn it into media. Direct media files you confirm are saved as local attachments. Web embeds show a video, map or any HTTPS page inside a note; only the address and display settings are stored, and the embed needs the internet when you view it.

Smart Paste

Some things you paste deserve more than plain text:

Illustration with sample data from the demo workspace.

  • Paste a URL over selected words to link those words without replacing them.
  • A pasted hex colour becomes an inline swatch.
  • A GitHub issue link becomes a compact repository and issue badge; it works offline and never loads issue details.
  • An absolute file path becomes a filename badge that opens the file through Windows when you activate it.

Undo restores what was there before in one step. Paste as plain text (Ctrl Shift V) skips conversion, and Convert to text in a badge's menu turns it back. Code and equations keep their normal paste behaviour.

Find, replace and focus

Ctrl F finds text in the page and Ctrl H replaces it. Focus mode (Ctrl Shift \) hides the sidebar and fades the top bar until you reach for it. Page width, text size, font and line spacing are yours to set in Settings › Editor.

Organising pages

Pages nest without limit. Drag them in the sidebar, use the menu to move them, or select several with Ctrl and Shift clicks and copy them with Ctrl C, even into another workspace. Favorites keep important pages at the top, breadcrumbs show where you are, and deleted pages wait in the Trash until you restore or remove them.
