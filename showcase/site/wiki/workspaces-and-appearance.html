Workspaces and appearance

Keep separate workspaces for separate parts of your life, and tune how Suivelle looks and moves until it feels like yours: colours, type, spacing, corners and motion are all preferences.

Workspaces

A workspace has its own pages, databases, templates and organisation. Keep one for personal notes, one for a creative project, one for work. Switch between them from the workspace row at the top of the sidebar; each remembers the page you last had open.

Give each workspace a name, a description, an emoji, symbol or image icon and a colour, and its own appearance if you like. Reorder workspaces by dragging or with the arrow keys.

Deleting a workspace asks you to type its name and offers Back up and delete, which saves a verified safety backup first, or Delete permanently. The last workspace can't be deleted.

Theme and colours

Choose light, dark or system appearance. The dark theme is a deep midnight navy with one sapphire accent; the light theme is warm paper with deep sapphire ink.

  • Accent presets and three full presets per mode.
  • A theme editor for backgrounds, text, accent and advanced roles, each with a swatch, exact hex field, picker and reset. Background roles can be partly transparent.
  • Live preview across the whole app before you apply.
  • Named themes you can save, duplicate, import and export as files.

The window and taskbar icon switch between the dark and light versions of the mark to match.

Type and reading

Settings › Editor sets page text size from small to extra large, a sans, serif or mono font for page text, page width (narrow, normal, wide or full) and line spacing, with a live reading sample.

Layout, corners and motion

Spacing
Compact, normal or relaxed. Every row, button, menu and gutter follows it.
Interface size
Zoom the whole interface from 90 to 150%.
Corners
Sharp, soft or round, applied to every radius at once. On Windows 11 the window itself can follow.
Lines
Soft, default or clear borders.
Motion
System, subtle or reduced. Reduced keeps short fades so changes never go silent, and stops everything that moves, scales or loops. System follows Windows when it asks for less motion.

Collapse the sidebar into an icon rail, hide it completely, or use focus mode to fade everything but the page.

Window and startup

Start Suivelle with Windows, optionally minimised to the tray, and choose whether the tray icon shows and whether closing or minimising sends the window there. Each workspace reopens on the page you last had open. The title bar is drawn in the theme's colours with standard window controls.
