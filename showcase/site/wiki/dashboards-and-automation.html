Dashboards and automation

See how a project is moving at a glance, collect entries without opening a table, and let small rules take care of the steps you repeat. All of it runs on your computer.

Charts

Any database can be charted, either as a chart view or as a dashboard widget. Charts are computed live from the records, so they are never out of date.

  • Bar
  • Line
  • Area
  • Pie
  • Donut
  • Number

Group by any property, count records or take the sum, average, minimum or maximum of a number, and filter to the slice you care about.

Dashboards

A dashboard is a page of live widgets: charts, single numbers, text, and linked views that show part of a database right there. Shared filters apply to every widget at once, so one dashboard can answer the same questions for a different sprint or area. Widgets resize smoothly as you lay them out.

Forms

A form view turns a database into a simple form. Choose which properties it asks for and in what order, with your own labels, help text and required fields. Each submission becomes a record, validated like any other, so bug reports, ideas or reading lists can be collected without touching the table. Forms live in the app; nothing is hosted online.

Local automations

Each database can have automations: a trigger, optional conditions written like a filter, and one or more actions. They run inside Suivelle, on your computer, while the app is open.

TriggersActions
A record is createdUpdate properties
A record is updatedSet a status
A property changes (optionally to a value)Create a record, optionally from a template
A date is reached, with an offset and a timeDuplicate the record
A schedule: every few minutes or hours, daily or weeklyArchive the record
Suivelle startsMove the record to the trash
A button property is clickedSend a desktop notification

Some examples: when a task's status becomes Done, stamp its completion date; every Monday at 9:00, create a weekly review record from a template; the day before a deadline, send a notification.

Loop protection stops automations from triggering each other forever. The Run log records each run with its result and the record it touched, so you can see what happened and why. Automations brought in from an archive arrive paused until you turn them on.
