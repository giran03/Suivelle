Search and navigation

Suivelle is built to be driven from the keyboard. One palette finds pages and runs commands, tabs and panes keep work open side by side, and today's note is always one shortcut away.

The command palette

Illustration with the demo workspace's pages.

Press Ctrl K. Start typing to search page titles and the text inside them, with snippets that show where each match is. Recent pages appear before you type. Narrow results by title or by date, and save searches you return to often; saved searches appear as soon as the palette opens.

The palette also runs commands. A few worth knowing:

  • Export current page as PDF
  • Create task in project: pick a project, type a title, optionally choose a task template
  • Backup workspace now
  • Dark mode, Browse tags…, Reminders…, Node Map

While the palette is open, the page behind it stays still; search, commands and scrolling inside the palette keep working.

Tabs

Open pages in tabs and switch with Ctrl Tab and Ctrl Shift Tab. Alt-click or middle-click a page in the sidebar to open it in a new tab. Ctrl W closes the current tab and Ctrl Shift T brings back the last one you closed. Drag tabs to reorder them, or move them with Ctrl Shift Page Up and Page Down.

Alt ← and Alt → go back and forward through the pages you visited.

Side by side

Alt-click a tab, or drag it to the right edge of the content, to open it beside the current page. Drag the divider to resize, or focus it and use the arrow keys. Open beside is in page menus too, including databases and dashboards. Shift-clicking a link opens it in the side peek instead, a quick editable panel from the right.

Daily notes

Ctrl Alt D opens today's note. Each day gets its own page, titled by date, inside a Journal page, so a running log builds itself. From a calendar, the same shortcut opens the selected day's note.

Quick capture

Catch an idea without leaving what you're doing: Ctrl Shift N or Quick capture in the palette opens a small capture box, and Enter saves it.

Reminders

Choose Remind me about this page and write a time in plain words, with an optional note. The reminder arrives as a desktop notification and, while Suivelle is open, as a message with an Open button. See Calendar and time for event reminders.

The tray and links from other apps

Suivelle can keep running in the system tray. The tray menu lists your most recent pages, and suivelle:// page links clicked in other programs open the page in Suivelle. Minimised or in the tray, the app uses much less memory.
