What's new

Highlights from recent versions. The full notes live in the changelog, and installed copies show them once after each upgrade.

0.1.5 · in development

Local AI agents

Suivelle can be the shared knowledge base for AI agents on your computer. Connect Claude Code, Codex, Cursor, VS Code and more in one click, review every change in an inbox, and revert anything from Activity. Agents get shared memory, a task queue, a plain-text Markdown mirror and vault health checks. Read more.

Node Map

A 3D and 2D map of every page in every workspace: focus, dive into neighbourhoods, search in place, choose layouts and save views, then connect pages, nest them or set dependencies right on the map, with undo. Read more.

Canvases

A freeform Canvas view for databases, and workspace canvases where whole pages can be edited on the board beside notes, images and labelled arrows. Read more.

Planning

  • Open tabs side by side with Alt-click or by dragging to the right edge.
  • A Master Calendar that overlays date properties from several project tables.
  • An Unscheduled Tasks drawer for time blocking in Day and Week views, and work sessions dragged from board cards.

Writing

  • Hover previews for mentions and links, [[ to link pages, and pages dragged from the sidebar into text.
  • Smart Paste for links over selected words, colour swatches, GitHub issue badges and file paths.
  • A copy button on code blocks, PDF export from the palette, and Create task in project.
  • Quiet shortcuts on empty pages for blocks, calendars and templates.

Smaller and faster

A consistent, locally bundled icon set throughout the app; a smaller download that uses less memory; and a startup that keeps the window responsive with a retry instead of a blank screen.
