Links, tags and backlinks

Notes become a knowledge base when they point at each other. Suivelle keeps those connections in both directions, finds the ones you forgot to make, and lets you read a linked page without leaving the one you are on.

Linking pages

Three ways to link, all of them two-way:

@ mention
Type @ and a few letters, then pick a page. The mention shows the page's icon and title, and follows renames.
[[ wikilink
Type [[ to pick a page the same way. Typing [[Page name]] for a page that doesn't exist yet links automatically once that page is created. Pages can have aliases that wikilinks also find. Brackets inside code stay as text.
Drag a page in
Drag a page from the sidebar onto the text of another page to insert a link to it. Dragging several selected pages inserts all of them.

Links can also point at a specific block. Following one jumps to that block and briefly highlights it.

Hover previews

Rest the pointer on a mention or page link to see a preview card with the page's title and opening lines. From the card you can open the page, or open it beside the current one.

Side by side

Shift-click a mention or link to open it in the side peek, a fully editable panel from the right. For a longer stay, Alt-click a tab or drag it to the right edge to split the view into two panes, with a divider you can drag or move with the arrow keys. Notes, records, databases and dashboards can all stay open together.

Linked to this page

At the bottom of every page, Linked to this page lists everything that points here. Each entry shows the whole paragraph around the link, with mentioned pages shown by title, and table rows that link here appear as Column: value pairs.

Below it, unlinked mentions list pages that name this page without linking to it, so you can turn them into real links.

Tags

Write #tags anywhere in a page. Browse tags… in the command palette lists every tag in the workspace with its count, and opens the pages that use one. Tags written before the feature existed are included.

The outline

Ctrl Shift O opens a floating outline of the page's headings. It marks the section you are reading, jumps to any heading, and shows word count, character count and reading time.

Seeing the whole web

The link graph in the command palette draws pages and the links between them for a quick look. For the full picture across every workspace, with records, layouts and editing tools, open the Node Map.
