Getting started

Suivelle is a desktop app for notes, projects and plans. It keeps everything in a workspace on your computer, works offline, and asks for no account. Here is how to go from installer to a working page in a few minutes.

Install

  1. Download the installer (@download-meta), or browse every release on GitHub.
  2. Run it. Suivelle installs for your user account and adds a Start menu entry. The installer also includes the small suivelle-mcp connector used by local AI agents; it does nothing until you turn agents on.
  3. Open Suivelle. A new installation opens on a short Getting started checklist page in your first workspace. Tick items off as you try them.

Want to look around first? The live demo runs the real interface in your browser with a fictional game studio workspace. It is read-only, so nothing you click changes anything.

Find your way around

The window has three parts: the sidebar with your workspace, favorites, recent pages and the page tree; a top bar with back and forward, breadcrumbs, search and page tools; and the page itself, which is the one thing that is lit.

Pages nest inside one another, as deep as you like. Drag them in the tree to reorder or move them, star the ones you visit often, and open several at once in tabs.

The five keys worth learning first

PressTo
Ctrl KSearch pages and content, and run any command from the palette
Ctrl NCreate a new page
/ in a pageOpen the block menu: headings, lists, tables, calendars, databases and more
Ctrl Alt DOpen today's note in your Journal
Ctrl /Show the shortcut reference

On a Mac keyboard layout, Cmd takes the place of Ctrl. Every shortcut can be changed in Settings › Shortcuts and input.

Make your first page

  1. Press Ctrl N and type a title.
  2. Press Enter and start writing. Markdown works as you type: # for a heading, - for a list, [] for a to-do.
  3. Type / for anything else. An empty page also offers quiet shortcuts to block commands, adding a calendar or picking a template; they disappear as soon as you write.
  4. Type @ or [[ to link another page. Links work in both directions, so the other page lists this one under Linked to this page.

Everything saves as you go. There is no save button, and page history keeps earlier versions if you change your mind.

Start a project from a template

Choose New from template to set up a ready-made project in one step. Each template creates its databases, views and a few example records you can delete:

Project Manager
Projects, milestones, sprints and tasks with subtasks, dependencies and live progress.
Task Tracker
One Tasks database with subtasks, dependencies, a board, a calendar and a timeline.
Software Project
The Project Manager setup with a task type (feature, bug, chore) and a Bugs view.

Your own pages can become templates too, and Import templates… brings in template files someone has shared with you.

Bring your notes with you

Import Markdown, plain text, HTML, CSV, whole folders of notes, supported Notion exports and Suivelle archives. Every import shows a preview first. See Data, backups and import for the details.

Stay up to date

Installed copies check GitHub for new versions, download them in the background and wait for you to choose Install and restart. Before installing, Suivelle saves your work and makes a verified backup of its data. After an upgrade, the changelog opens once so you can see what changed. You can change how updates behave in Settings › Updates.
