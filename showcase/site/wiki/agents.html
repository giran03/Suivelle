Local AI agents

Suivelle can be the shared memory for AI coding agents on your computer, such as Claude Code and Codex. Agents read your notes, record what they learn and propose changes. You decide what applies, and you can undo any of it.

New in 0.1.5, currently in development. Suivelle never runs a model and never starts an agent. Agents connect over a private connection on your own machine, only while you have it switched on, and nothing is sent over a network.

How it works

  1. Turn it on in Settings › Agents › Let local agents connect.
  2. Connect an app. Connect apps finds agent apps on this computer and connects one in a single step, showing exactly which file it will change first.
  3. Work as usual. The agent asks Suivelle for context, searches and reads pages, writes memories, and proposes edits through its own token.
  4. Review. Changes wait in the Review inbox, or apply directly, depending on the agent's mode.

Connect gives the app its own agent and token and adds one suivelle entry to the app's MCP settings, using the app's own command where it has one. Only that entry is touched; everything else in the file stays byte for byte, the previous file is kept as a backup, and Disconnect takes the entry out again. On Windows the token is kept in Credential Manager rather than in the app's files. Each app shows whether it is connected, needs a restart, or needs Repair.

Connect can also add a few lines that make the app start each session from Suivelle, and four commands: /suivelle_init, /suivelle_setup, /suivelle_sync and /suivelle_wrap-up. Both options show their exact files first.

Review every change

Illustration with sample pages from the demo workspace.

Each agent has a mode:

ModeChanges to pages
Propose (default)Wait in the Review inbox with a line-by-line preview
AutoNew pages, records and additions apply at once; edits to your pages wait
WriteApply at once

Approve all, approve some, or reject with a note the agent can read. An agent waiting on your decision carries on the moment you answer; if its session has ended, it gets a Continue task for next time. Activity lists every change any agent made and reverts any of them.

Some pages always wait for review, whatever the mode: an agent's instructions page and pages named Agent protocol or Agent command: …, because they steer every agent that reads them. Agents never hard-delete anything, never touch settings, backups or the trash, and cannot change their own permissions.

Agents, memory and tasks

Agent Hub
Each workspace gets an Agent Hub page. Every agent has an instructions page there, and a page named Agent protocol is handed to all agents as shared rules.
Shared memory
Agents record facts, decisions and preferences in a Memory database, correct them by superseding rather than overwriting, and recall them by topic. A context pack gives an agent a page, what it links to, matching memories and its open tasks in one briefing.
Task queue
Queue work in the Agent tasks database, or choose Queue for an agent on a to-do. Agents claim a task for 30 minutes at a time; one that stops reporting goes back to the queue. Finishing a task that came from a to-do checks it off.
Permissions
Choose which workspaces each agent can see and what it may use: pages, links and tags, databases, memory, tasks and vault health checks.

Plain-text mirror

Optionally keep a folder of Markdown files in step with a workspace, so agents, editors, search tools and git can use your notes as plain text. Pages link with [[wikilinks]]. Edits made in the folder come back through the Review inbox, or apply directly if you choose. When a page changed in both places, the folder's version is kept beside it as a .conflict.md file.

Vault health

Vault health checks a workspace for broken links, [[links]] to missing pages with likely matches, duplicate titles, empty and isolated pages, tag spellings, and stale agent memories and tasks. Pick the fixes you want, apply them together, and revert them from Activity if needed.

For developers

Import Claude Code subagents from your user folder or a project, export an agent as a Claude Code subagent file, or write an AGENTS.md section into a project that lists your agents and how to reach Suivelle. The connector, suivelle-mcp, ships with the installer and stays up to date in one place.
