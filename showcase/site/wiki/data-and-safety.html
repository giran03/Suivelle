Data, backups and import

Your workspace is a folder on your computer. Suivelle works fully offline, needs no account, and is built around one rule: never lose your work.

Local first

Pages, databases and settings are stored in a local database, and attachments as files beside it. Editing never touches the network. The only things that go online are the ones you ask for: web embeds when you view them, links you open, and update checks.

Local storage still depends on your computer's health. Keep independent backups of anything important, for example by pointing the second backup copy at an external drive.

Page history and the trash

Every page keeps a version history. Preview an earlier version and restore it in one click. Deleted pages go to the Trash, where you can restore them, or remove them for good when you are sure.

Backups

Automatic
A verified backup once a day, keeping the newest three by default (anything from 1 to 1,000). Cleanup never removes manual or safety backups.
Manual
Back up now from the Backups window or the command palette. It saves edits still open in any editor first.
Second copy
Each automatic backup can also be saved to another folder, such as an external drive. If it's unavailable, backups carry on as usual.
Restore
Browse saved backups and restore one safely. Backups use the .suibk extension; older .takobak backups remain readable.

Safe upgrades and recovery

Before an upgrade changes the database, Suivelle saves a copy first; without that copy, the upgrade doesn't run. If a workspace fails its integrity check or an upgrade fails, Suivelle opens it read-only with a banner explaining why, so you can export it or restore a backup instead of facing a blank screen.

App updates save your work and make a verified backup of installation data before installing.

Storage health

Settings › Data and backups shows what is stored and how much space it takes, cleans up files nothing uses, compacts the database, checks its integrity and rebuilds search.

Import

Every import shows a preview before anything is created.

  • Markdown
  • Plain text
  • HTML
  • CSV
  • Folders of notes
  • Notion exports
  • Suivelle archives
  • Calendar .ics

Importing a workspace archive creates a separate workspace by default, with collision-safe names and optional appearance. Automations arrive paused. An import that can't finish rolls back completely.

A databaseCSV
Calendar events.ics
A whole workspaceA readable zip archive with content, files, templates, views, dashboards, canvases, calendars, automation definitions and internal links

Workspace export saves pending edits first and refuses to write an archive with missing or damaged files. Trash, page history, backups and automation run logs are not included; full recovery lives in Backups.

Reporting a problem

Copy diagnostic report in Settings › About, and on the error screen, gathers technical details for a bug report. It never includes your notes. Report bugs on the issue tracker, and suspected vulnerabilities through the security policy.
