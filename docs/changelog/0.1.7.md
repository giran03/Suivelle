# Suivelle 0.1.7

Released October 21, 2026.

## Editor

- Select blocks of different types and choose **Merge all into…** to combine them into text, a heading, quote, callout, code, list, toggle, or tabs. Keep line breaks or combine text with spaces. Lists, toggles, and tabs retain embedded blocks; text targets use their names or URLs. Merges support undo and redo.
- **Copy text** copies selected text or multiple selected blocks as plain text, preserving line breaks. Block menus also offer **Copy image**, including displayed crops and animated still frames; when several images are selected, choose which image to copy.

## Settings

- Increased line spacing and separation between descriptions, paragraphs, status messages and expanded details throughout Settings.

## Local AI agents

- Added a separate hour-by-hour chart for the last 24 hours, with stacked input and output tokens, local-time labels, and exact hourly totals.

- Restyled the usage trend with slim stacked bars, token-axis gridlines, a context-token total, and detailed values on hover or keyboard focus.

- Install or update a bundled REA workflow from Settings > Agents for use across projects, only on explicit request. No Jev key is needed; disabling Jev keeps installed files and uses human or independent agent review.

- Aligned the Jev toggle with its health-check and API-key buttons in Settings > Agents.

- Connected agent apps now show a setup checklist for their connection, instructions and commands, and first successful session check. Install or repair setup files without replacing the token; manual steps and partial installations stay visible.

- Optional Jev memory filter in Settings > Agents: add a TypeSafe AI Jev API key (with a live Health check button) to rank recalled memories by meaning, leave irrelevant memories and connected pages out of context packs so agents use fewer tokens, and catch duplicate or conflicting memories even when they share no words. When off or unreachable, Suivelle uses local search.
- Token and Jev usage analytics in Settings > Agents and Agents > Usage: see tokens sent and received, tokens saved by context trimming and Jev pruning, cache hits, latency, daily and hourly activity, per-agent and per-tool breakdowns, and recent call logs across 24h, 7d, 30d, or all time.
- Documented a shared REA workflow for external agents across projects, used only on explicit request, with role prompts, evidence and specification templates, human review checkpoints, and a mutation-test checklist.
- Agents start sessions with fewer tokens: Suivelle's tool list is about 30% smaller, `whoami` leaves out the Agent protocol when the agent already has the current version, and Vault health offers to remove an outdated instruction that made agents read the protocol a second time.
