# Suivelle 0.1.4

Released 2026-10-14.

## Added
- Open today's note with Ctrl+Alt+D or from the command palette. Each day gets its own page, titled by date, inside a Journal page.
- Remind me about this page: pick a time in plain words ("tomorrow 9am", "friday at 14:00", "in 3 days") and an optional note. The reminder arrives as a desktop notification and, while Suivelle is open, as a message with an Open button. Reminders… lists what is coming up and what fired in the past week.
- Write #tags anywhere in a page and browse them with Browse tags…; existing notes are included.
- Link graph shows pages and the links between them. Pan, zoom and click a page to open it, or switch to a list.
- Open a page beside the current one: Shift+click a mention or link, or choose Open beside in the page tree. The side peek is fully editable.
- The outline (Ctrl+Shift+O or the top bar) lists the page's headings, marks where you are, and shows words, characters and reading time.
- Reopen a closed tab with Ctrl+Shift+T.
- Save searches in the command palette; saved searches appear when the palette opens.
- Backlinks also list unlinked mentions: pages that name this page without linking to it.
- The tray menu lists your most recent pages. suivelle:// page links clicked in other programs open in Suivelle.
- Web embeds: show a video, map or other HTTPS page inside a note. Only the address and display settings are stored.
- New workspaces can start with an image icon, and workspaces can be reordered by dragging or with the arrow keys.
- Storage health in Settings → Data and backups shows what is stored, cleans up files nothing uses, compacts the database, checks its integrity and rebuilds search.
- Second copy: each automatic backup can also be saved to another folder, such as an external drive. If it is unavailable, backups continue as usual.
- Copy diagnostic report in Settings → About (and on the error screen) for bug reports. It never includes your notes.
- New installations open on a short Getting started checklist. Import templates… brings shared template files into your Templates.
- Calendar blocks offer month, week, day, agenda and year views, with per-block sources, colors, timezones and working hours. Connect native event calendars and database date properties, schedule undated records, and drag or resize items to update their dates.
- Calendar events are pages with rich notes and optional templates. Schedule a page block as a linked event, duplicate an event, use quick-add date phrases, and set location, busy/free status, completion and reminders while Suivelle is running.
- Repeat events daily, weekly, monthly or yearly; edit or remove one occurrence, future occurrences or the whole series. Import and export supported events as .ics files; workspace archives retain calendars, schedules and internal links.
- Calendar day details show scheduled items, planned and occupied time, overlaps and a shortcut to that day's journal. A plus button beside the day number opens the new-event form.
- Pasting a supported media URL asks whether to convert it into an image (including GIF), audio, video, PDF or supported web embed. Choosing to keep the link leaves it as text; confirmed direct media files are saved as local attachments.
- In a table cell, Ctrl+Enter inserts a row below and Ctrl+Shift+Enter inserts a column to the right, then moves the cursor into the new cell. Both shortcuts can be customized; an info icon beside the table shows the current bindings.

## Improved
- If the workspace cannot pass its integrity check or an upgrade fails, Suivelle now opens it read-only instead of refusing to start, so you can export it or restore a backup.
- Before an upgrade changes the database, a copy is saved first; without that copy, the upgrade does not run.
- Suivelle uses much less memory while minimized or in the tray, starts with less code, and checks the database at startup only after an unexpected shutdown.
- Global shortcuts have an Enable or Disable button; enabling one with no keys assigned restores its default keys.
- Replaced the window-corner toggle with independent Sharp, Soft and Round icon buttons. Soft uses Windows’ smaller corner radius, while Round uses its fuller radius. The choice is remembered across restarts; Sharp explicitly keeps the window square.
- New backups and backup exports use the .suibk extension. Existing .takobak backups remain available to browse and restore, including automatic backup retention and second-copy cleanup.
- Workspace settings use an icon-only workspace rail; the workspace dropdown has a compact icon toolbar for creating, configuring, importing and exporting workspaces. Page-tree expand and collapse controls also use icon buttons.
- Dropdowns open at their final size with themed transitions; scrollbars stay hidden during the animation. Floating menus and dialogs now use the intended theme-aware shadows.
- Multi-day calendar events keep their duration when their start changes, validate through dates, and use optional automatic event colors. Hovering or focusing a range highlights all of its segments; narrow bars fit their labels or show a dot with the title in a tooltip.
- Event date pickers have animated opening and closing, rounded corners, circular date selection and a calendar icon that becomes a close button while open. Event dialogs close when clicking outside, and their labels stay unselectable while fields remain editable.
- Removed selection frames around editor blocks, media and embedded content, and browser focus frames around dialogs and popups. Keyboard controls and active database cells retain themed focus cues; high-contrast focus indicators remain visible.
- Settings → About can add a fresh Getting started checklist to the current workspace. The shortcut reference shows the to-do brackets as separate keys, and its title, labels and Customize button no longer select text accidentally.
- Switching Light or Dark in Custom colors selects the first preset for that palette and shows Apply immediately. Colors and the app mode are saved only after applying.
- The system tray icon follows the same Light, Dark and System theme changes as the taskbar and title-bar icons.
- Event editors have a sticky footer with labeled icon tools for copying links, setting a 15-minute reminder, duplicating and opening the event page. The trash action is separated from the other tools, and Cancel and Save stay grouped on the right.
- Event dates use one range field with rounded calendar endpoints, a highlighted span, month/year navigation and editable start/end times for timed events. Apply range commits the selection; Cancel or clicking outside discards it. Switching All day preserves the selected dates. Picker labels stay unselectable, and native date/time fields no longer show the blue segment highlight while editing.

## Fixed
- The import preview no longer scrolls sideways.
- Links in the main editor, side peek and nested editors now open consistently; external links, linked images and embed browser buttons use the same opening behavior.
- Workspace badges and dropdown rows keep their intended spacing and alignment when the workspace picker opens before workspace settings.
- Calendar weekend shading no longer hides the divider between Saturday and Sunday.
- Image toolbar controls no longer inherit the image filename tooltip between buttons.
- The startup splash restores saved appearance colors before the app opens.
