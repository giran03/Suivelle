# Suivelle 0.1.3

Released 2026-10-13.

## Added
- Copy selected pages in the hierarchy with Ctrl/Cmd+C, switch workspaces, and paste with Ctrl/Cmd+V inside a page or use Paste pages at top level. Nested ordinary pages come along, overlapping parent/child selections copy once, and both shortcuts can be rebound.
- Import from Notion: choose a Notion export (the zip as Notion saved it, or its unpacked folder, in Markdown & CSV or HTML) and Suivelle rebuilds it, with subpages, databases and their column types, record pages, relations, callouts, icons and covers. Large exports split into parts import in one go, and a whole-workspace export can become a workspace of its own.
- PDF files can be imported; each becomes a page that shows it.
- Export works like Notion's: choose Markdown & CSV, HTML or PDF (one page), whether to include subpages, files and every database row, and whether subpages go in folders. Exports of more than one file are saved as a single zip that Notion, or Suivelle, can import back.
- Customize shortcuts in Settings → Shortcuts and input: bind keyboard keys with modifiers or mouse buttons detected by the app, choose logical or physical keys, and assign multiple alternatives to an action.
- Record a shortcut or choose it manually, test incoming input, resolve conflicting bindings, disable individual actions, and restore defaults. Shortcut preferences are saved per device.
- Rebind the system-wide quick capture and app-focus keyboard shortcuts, with controls to enable or disable them and feedback when a shortcut cannot be registered.

## Improved
- Context-menu actions show right-aligned keycaps for applicable shortcuts, following custom bindings and acting on the clicked item. Shortcut settings use the same separate keycaps without inline × controls; individual bindings can be removed from their editor.
- Dropdowns throughout databases and boards are restyled: consistent heights, spacing and corners, an accent-highlighted selected option, and sizes that follow the Spacing setting in Appearance.
- Collapse the sidebar into an icon rail from beside the workspace switcher: workspace image, search, pages and utility buttons stay within reach, and the collapse arrow animates as it changes direction. Expand it from the rail; the toolbar button fully hides or shows the sidebar, restoring its previous expanded or collapsed state. Desktop sidebar width, collapse state and visibility are remembered; on narrow windows, navigation uses the full width and closes when a page is selected or Escape is pressed.
- Shortcut reference, command palette hints and toolbar tooltips follow your configured bindings across workspace navigation, editing, pages, databases, tabs and quick capture.
- Sidebar, toolbar and shortcut settings layouts adapt to small windows, zoom and Appearance spacing settings, with wrapping controls and consistent spacing.
- Only one Suivelle instance runs at a time. Opening the app again brings the existing window forward, restoring it if minimized or hidden in the tray.

## Fixed
- Workspace dropdown rows stay inside the menu at different zoom and spacing settings. Long names and descriptions wrap without overlapping icons or the selected checkmark.
- Selecting a workspace in Workspace settings shows its settings without switching the active workspace or page; saves, icon uploads and exports target the selected workspace.
- Page surfaces and navigation no longer display outer focus outlines in normal themes; keyboard focus indicators for controls and high-contrast themes are preserved.
