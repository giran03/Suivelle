# Suivelle 0.1.6

Released October 16, 2026.

## Split view

- Split the window into several panes. Choose Side by side, Stacked, Four corners, Master and detail, or Tiles (three to six) from the new Split view button in the top bar or from the command palette. Every kind of page opens in a pane, including databases and dashboards.
- Drag a page from the sidebar, a tab, or a pane's header over the window and an outline follows the pointer to show where it will land: the edges of a pane dock it there, splitting that pane in two, and the middle swaps it in. Panes glide to their new places, and the main page can be docked too. Layouts are no longer limited to the presets, and there are no empty panes: presets keep the panes you already have open, then fill from favourites and top-level pages.
- Drag the dividers to resize panes, use the arrow keys on a focused divider, or double-click a divider to even them out. Closing a pane gives its space to its neighbours. Open beside now uses the same panes.

## Local AI agents

- /suivelle_init now adds the lines that make an agent app start every session from Suivelle by itself when they are missing, instead of asking first. Suivelle adds them at the end of the app’s own instructions file and keeps everything already there exactly as it was, with a backup of the previous file; instructions you wrote yourself are never changed or removed, and lines you added by hand count as already there. Disconnect takes the added lines out again.
- Agents find the right memories more often. A search matches a memory when its words are spread over the memory's title, text and scope, memories with more of the words come first, and older memories are no longer missed in a large memory database or behind ordinary pages that use the same words.
- Memories stay in their project. A context pack for a project's page only includes that project's memories (and those with no scope, after them), and a scope such as “ui” no longer matches “suivelle”.
- Agent briefings are shorter and complete. Memories leave out default details, long memories are shortened with a pointer to the rest, nothing is cut off halfway, and what did not fit is listed with how to get it. An agent that already has a page can skip it when it has not changed.
- Starting a session takes fewer steps: whoami lists each workspace's project pages, and context_pack takes a project name.
- Recording a memory that is already there writes nothing, a similar memory in the same scope is pointed out, and a memory that was already replaced can't be replaced a second time by mistake.
- Vault health points out active memories in the same scope that seem to say the same thing, and can mark the older one superseded. It only does so when you choose the fix; the hourly upkeep leaves them alone.
- Vault health tells you when your “Agent protocol” page is older than the one Suivelle now ships, and can replace it with the current text. A page you wrote yourself is only noted, and its old text stays in the page history.
- When several memories match a search equally well, the newer one comes first.

## Editor

- Turn several selected blocks into another block type at once from the right-click menu, the block handle menu, or keyboard shortcuts. Text, headings, quotes, callouts, lists, and toggles convert each block in place; Turn into Code joins the selected blocks into one code block; Turn into Tabs and Turn into synced block group the selected blocks together. When several quotes, callouts, or paragraphs are selected, Merge into one quote, callout, or paragraph combines them into a single block.

## Fixes

- Imported themes use the file name and are selected in your library. Saving a theme clears the name field; exports keep the selected theme’s name and suggest a matching file name.
- Switch straight to a built-in color preset or any saved or imported theme from the command palette. Search for “theme presets” or a theme name. The list updates automatically as your theme library changes; saved themes apply both palettes and keep your current light, dark, or system mode.
- Switching between Light and Dark in the palette editor now previews that mode across the app. The saved mode changes only when you Apply; Cancel, Discard or turning off app preview restores the saved appearance.
- Theme preset buttons smoothly expand to reveal their color dots on hover or keyboard focus, then shrink when you move away. Reduced motion skips the resize, and touch devices keep the dots visible.
- Added Sage and Lavender color presets for light mode, plus Plum and Ember for dark mode. Each mode now offers five palettes.
- Color previews in the theme preset picker now appear as circular dots.
- Icons, emoji and workspace badges line up consistently in the Node Map list, with page titles kept clear of their icon column.
- Page-link previews stay open while you hover over the card or use its Open and Open beside buttons. Moving away or clicking elsewhere still dismisses the preview.
- Tabs no longer show a text selection highlight when you drag or double-click them.
- Dragging a tab now lifts it under the pointer while the other tabs slide aside, and page-link previews no longer show an "Empty page" placeholder.
- Quick Capture and Trash load when opened, keeping the main window’s startup bundle small.
- Pages already listed in the sidebar open immediately while their latest details load in the background.
