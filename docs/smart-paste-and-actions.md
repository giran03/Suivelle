# Smart Paste and quick actions

Paste a single web URL over selected words to link those words without replacing them. A standalone hex color becomes a swatch; a GitHub issue URL becomes a repository/issue badge; an absolute file path becomes a filename badge. The complete reference remains available through the tooltip and context menu. GitHub badges work offline without loading issue details.

Use Undo to restore the state before paste, or right-click a reference and choose **Convert to text** to keep its original value as ordinary text. **Paste as plain text** bypasses conversion. Code and equations keep their original paste behavior. File badges open documents through Windows after you activate them; pasting does not open or import files. Missing files and paths from another computer remain copyable.

Open the command palette with the configured Search shortcut (Ctrl+K or Cmd+K by default). Search for **Export current page as PDF**, **Create task in project**, **dark mode**, or **backup workspace now**.

Project starters created in this version register their task/project destination automatically. For an existing or custom setup, choose the task database and its relation to the project database once. The palette remembers the relation by its ID, so renaming a database or property does not break it. Choose a project, enter a title, optionally choose a task template, and create the task. Escape returns from the title step to projects; closing the palette cancels before creation. The task and its project relation are saved together.

On an empty ordinary page, use the subtle starter row to open block commands, add a calendar, or pick a template. Your page templates apply to that page and preserve its title. Project starters create their own new pages and databases. Hints disappear when body editing or text composition begins and stay hidden until the next visit to the empty page.
